# 本地数据与网络边界

XML 编辑和音视频匹配在本机进行。应用不需要云端大模型，不提供 Gemini 配置或媒体上传复核入口。

选择 B 站、Emby、WebDAV、TMDB 或私人弹幕库等接入时，应用会向所选服务发送完成操作所需的请求。只有本地匹配不代表整个应用没有网络功能。

项目备份包含弹幕正文、媒体路径、编辑状态和相关元数据，不包含视频本身。分享备份前请检查个人路径、弹幕用户名标识和服务地址。截图、日志、授权播放地址也可能包含私人信息；不要直接提交到公开 issue。

Windows 上的 B 站、WebDAV、LogVar 和旧专用库凭据使用系统 DPAPI 保护；Emby 密码仅保留于当前进程，并绑定服务器和账号。项目、原始 XML 副本、恢复数据及媒体特征不是凭据保险箱，依赖本机账号和文件系统权限。完整音频缓存可以还原声音；画面指纹不保存截图。

匹配使用用户配置的 FFmpeg/FFprobe，预览可加载 libmpv。只使用可信安装。导入项目中的网络共享路径不会被默默打开，Emby 凭据不跟随跨来源重定向。LogVar 接入上传由所选 XML 转换的兼容 JSON；旧专用库沿用 gzip JSON 协议。原始 XML 留在本地。

## 首次安装与升级

配置文件在当前用户的 `%APPDATA%/studio.danmaku.timeline` 下；项目库与凭据默认位于该用户的 `%LOCALAPPDATA%/studio.danmaku.timeline` 下。自定义存储目录留空时采用当前用户的默认目录，默认导出到数据目录下的 `exports`。B 站账号与私人库连接由用户按需配置。

升级会保留当前 Windows 用户已有的路径、账号与连接。导入设置备份、复制应用数据或共享 Windows 账号时，请留意这些数据的使用范围。

B 站凭据保存在 `bilibili/credential.dpapi`；LogVar 与旧专用库分别保存在 `logvar-library/connection.dpapi`、`private-library/connection.dpapi`。LogVar 不复用旧服务凭据。界面只回显不带 TOKEN 的服务根地址，复制播放器地址是用户主动操作，复制结果包含 TOKEN，需妥善保管。

删除工作树文件不会删除旧 Git 历史。项目发布维护者应使用经过检查的公开源码集合，确认不包含个人路径、凭据、私人素材、截图、运行清单或开发历史文档。
