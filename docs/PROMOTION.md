# 宣传文案草稿

收藏里想看的视频，回头却找不到了；好不容易找到另一个版本，又遇上删减、填充、分 P 和错位的弹幕。

我们想要清晰完整的画面，也舍不得弹幕里一起观看的氛围。

Danmaku Studio，让你把自己的弹幕带回原片。保存仍可访问稿件的弹幕与参考音频，导入你准备好的原片，在本机完成匹配、检查和导出。音轨不同？也可以用 AAP 比较两侧画面，建立分段时间关系。

原始文件保持原样，你整理好的弹幕留在自己手里。

## 演示时准确说明

- 需要自己准备原片；AAP 还需要参考视频。
- 获取弹幕和参考音频不等于完整视频归档；不能找回已经下架的稿件。
- 自动匹配减少定位工作，复杂剪辑仍可能需要确认。
- 导出的文件可交给支持相应格式或兼容接口的播放器；不要未经实测宣称所有播放器直接兼容。

视频建议展示一组自己制作的素材：原片 → 加入填充和删减 → 自动匹配三段 → 检查填充区 → 导出 XML → 在原片播放。这样观众可以直接看到 Studio 解决的问题，也不会泄露私人收藏或账号。
