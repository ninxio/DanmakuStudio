# 使用指南

## 素材 → 匹配 → 编辑 → 导出

1. 在素材页导入 XML。只需修改弹幕内容或整体偏移时，直接开始编辑。
2. 需要迁移到另一版本时，导入弹幕原本对应的参考媒体，以及最终观看的原片；把 XML 绑定到正确的参考素材。原片与参考素材可以有不同分段。
3. 在匹配页选择音频或 AAP 画面模式，然后选择两侧素材开始计算。音频模式需要可用音轨；AAP 需要两侧视频，不需要音轨。音频缓存不能替代 AAP 的视频输入。
4. 从候选结果进入编辑页检查。对照预览、确认共同内容，调整版本差异和边界；重复镜头及未匹配区域需要判断。颜色或分数不等同于正确率。
5. 确认关系并完成导出检查，再按目标原片导出。未确认内容不会被自动填到最近的时间点。保留输出文件，实际播放检查观感。

AAP 一次最多选择 64 个素材组合，串行运行并复用最多四份本次进程内的画面指纹；不会创建无界解码并发。停止会等待原生进程退出，保留已完成候选。离开 AAP 页面会请求停止当前任务，完成的候选随项目保存，未完成组合需要再次选择运行。

## 保存与恢复

桌面项目自动保存到本机项目库，以“已保存”状态为准。可从最近项目继续，也可导出和导入项目备份。项目不嵌入视频；视频移动后需要重新连接。更换媒体或时间图会使旧验证失效。原始 XML、视频和已经导出的成品不会因编辑而被覆盖。

## 获取素材

“从 B 站获取”可保存可访问稿件的弹幕和参考音频；这不是完整视频归档，也不能恢复已下架的稿件。账号登录和平台可用性会影响获取结果。AAP 的参考视频需要另行准备。

Emby 和 WebDAV 可读取已配置服务的素材或获取音轨，Motrix 可承接用户选择的下载。服务器密码只应输入到你信任的连接设置中。导入项目不能替换已保存密码所属的账号或服务器。UNC 网络共享路径不自动访问，先保存为本地文件，或使用显式 Emby/WebDAV 连接。

私人弹幕库默认连接自己部署的 [LogVar / danmu_api](https://github.com/huangxd-/danmu_api)。在“设置 → 私人弹幕库”填写带 TOKEN 的接口地址和可选 ADMIN_TOKEN。上传前选择已有影视或填写片名、年份、类型和季集，预览新增/替换范围；另可只补缺集。Studio 在内存中把 XML 转为兼容 JSON，经 LogVar 本地弹幕接口上传后，从播放器接口回读核验；原 XML 不变。格式、容量、并发边界及完整步骤见 [LogVar 接入](LOGVAR.md)。已有旧专用连接保留独立兼容入口。

## 工具与排错

- 匹配无法启动：在设置中检查 FFmpeg/FFprobe 路径，两者应来自兼容安装。
- AAP 提示无视频流：确认导入的是视频文件，而不是 `.m4a` 等音频缓存。
- 视频无法预览：检查 libmpv；网页预览不能替代桌面后端验证。
- 几乎没有共同内容：检查素材是否属于同一内容；大幅裁切、重绘、字幕遮挡或镜头乱序可能需要手动对齐。
- 密码未被复用：在设置中核对项目对应的 Emby 服务器、路径前缀和用户名，再保存当前会话密码。
- 导出被阻止：进入编辑页处理未确认区间，检查当前媒体身份和验证状态。不能通过把相似度当作验证结果跳过检查。

匹配特征缓存可以重算，清理不会删除项目或原始文件。AAP 指纹缓存只在应用进程内保留，随应用关闭释放；设置中的清理动作也会清除此缓存。
